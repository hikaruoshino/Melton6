================================================================================
 Melton6 v1.1.1 コマンド一覧
================================================================================
 コマンドは //m6 または //melton6 で始めます。
 チャット内で //m6 だけを入力すると簡易ヘルプが出ます。
 ゲーム内マクロから使うときは /console m6 go のように書きます。

 ※ Melton6 は、マクロ 1 回の操作でアビリティと魔法の入力を
    自動で送る「自動キャスト」アドオンです。入力は通常 16 回
    (強化の選択によって 15〜17 回。連環計・黒のグリモアが効果中なら少なくなる。
    不発の使い直しは含まない)。1 回押せば 1 回だけ実行し、
    失敗したらその場で止まります。放置・無人では使わないでください。
    外部ツールの利用は FFXI の利用規約で認められていないため、自己責任で。


--------------------------------------------------------------------------------
■ 基本操作
--------------------------------------------------------------------------------
 //m6 go   (または //m6 start)       6連メルトンを開始
                                      連環計 → 黒のグリモア (効果中なら飛ばす)
                                      → 震天 エアロ → ストーン → エアロ
                                      → 土門の計 → 風門の計 → 闇門の計 (重力)
                                      → 強化 (boost の設定。初期は気炎万丈の章) → メルトン
                                      (気炎万丈の章だけなら、重力から約 5.7 秒で着弾)
 //m6 stop                            途中で止める
 //m6 check                           開始できるか確認だけする (何も実行しない)
                                      ジョブ・ターゲット・距離・再使用・MP を確認
 //m6 status                          設定と実行中の段を表示


--------------------------------------------------------------------------------
■ 強化の選択 (v1.1.0)
--------------------------------------------------------------------------------
 //m6 boost <ebullience|enlightenment|both|none>
                                      メルトンの前に使う強化を選ぶ (初期 ebullience)
                                      ebullience    : 気炎万丈の章だけ (従来どおり)
                                      enlightenment : 大悟徹底だけ
                                      both          : 大悟徹底 → 気炎万丈の章
                                      none          : 強化なし (重力のあと postfinal の待ちでメルトンへ)
                                      選んだ強化が実行されなければ止まる (both で 1 つ目が不発なら 2 つ目へ進まない)
                                      大悟徹底は MB 受付 (重力から約 7 秒) に間に合わない可能性あり。
                                      間に合うかは自分で確かめる (ゲーム内未確認)


--------------------------------------------------------------------------------
■ /p のセリフ (v1.1.0)
--------------------------------------------------------------------------------
 //m6 say                             今のセリフを一覧表示
 //m6 say <start|1|2|3|4|5|6|mb> <文>  セリフを設定する
 //m6 say <キー> off                   そのセリフを消す
                                      start : 開始直後
                                      1     : 1 発目 (エアロ) の着弾を確認した直後
                                      2〜6  : その段の連携の成立を確認した直後
                                      mb    : メルトンの詠唱を始める直前
                                      初期は空 (何も送らない)。文は利用者が自分で入力する
                                      パーティーに他のメンバーがいるときだけ /p で送る
                                      拒否する文: 先頭が /・制御文字・半角の ; ・Shift-JIS で 100 バイト超
                                      (拒否しても設定は変わらない)。100 バイトは安全側の制限で、
                                      FFXI 本来の上限は未確認


--------------------------------------------------------------------------------
■ 設定 (data/settings.xml に保存)
--------------------------------------------------------------------------------
 //m6 set post <秒>                   魔法の着弾から次のアビリティまで (初期 3.0・0〜10)
                                      連携が起きにくいときに調整
 //m6 set postfinal <秒>              最後の重力の着弾から気炎万丈の章まで (初期 3.0・0〜5)
                                      魔法のあとの硬直 (約 3 秒) のため短くしすぎない。MB 受付は 6 連で 7 秒 (v1.0.2)
 //m6 set gap <秒>                    アビリティの後の待ち (初期 1.0・0.5〜5)
 //m6 set jatimeout <秒>              アビリティの実行を待つ秒数 (初期 2.5・0.5〜10)
 //m6 set boosttimeout <秒>           強化 (気炎万丈の章・大悟徹底) の実行を待つ秒数 (初期 1.5・0.5〜5)
                                      MB 受付 (7 秒) に間に合わせるため短め。不発ならメルトンの前で止まる
 //m6 set retries <回>                アビリティが実行されなかったときに使い直す回数 (初期 1・0〜2)
                                      気炎万丈の章は使い直さない
 //m6 set casttimeout <秒>            詠唱開始を待つ秒数 (初期 2.5・1〜10)
 //m6 set landtimeout <秒>            詠唱開始から着弾を待つ秒数 (初期 12.0・3〜30)
                                      範囲の外を指定すると、範囲の中に収めて知らせる (v1.0.1)
 //m6 tabula                          連環計が切れていたら自動で使うか (ON/OFF、初期 ON)
                                      メルトンは連環計の効果中しか詠唱できない


--------------------------------------------------------------------------------
■ 止まる条件 (理由をチャットに表示)
--------------------------------------------------------------------------------
 ・詠唱が中断された / 詠唱が始まらない / 着弾を確認できない
 ・狙った連携が起きなかった
 ・アビリティが 2 回とも実行されなかった
   (強化 (気炎万丈の章・大悟徹底) は、1 回でも実行されなかったとき。
    実行として数えるのは boosttimeout の間に届いたものだけ。遅れて届いたものは数えない (v1.1.1))
   使い直したときに、もう一方の実行が遅れて届いても、後の手順の実行としては数えない (v1.1.1)
 ・魔法の着弾は、開始したときにターゲットしていた敵へのものだけを受ける。
   別の敵への手動の詠唱の着弾では進まない (v1.1.1)
 ・ターゲットが変わった・倒れた / エリアを移動した / 戦闘不能になった
 ・//m6 stop
