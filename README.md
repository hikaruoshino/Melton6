# Melton6 (v1.0.2)

**ファイナルファンタジーXI（Windower 4用） 学者の震天動地の章による 6 連携 → メルトン MB を、マクロ 1 回で実行するアドオン**

ゲーム内マクロに 1 行 `/console m6 go` を入れて押すだけで、6 連携からメルトンのマジックバーストまでを順番に実行します。

固定の待ち時間ではなく、**アビリティの実行と魔法の着弾をアクションパケットで確かめてから次へ進みます**。途中で連携が途切れたり、詠唱が中断されたりしたら、その場で止まります。

---

## 自動キャストアドオンです（必ずお読みください）

Melton6 は、**マクロ 1 回の操作で、アビリティと魔法の入力（通常は 16 回。アビリティが不発のときの使い直しを除く）を自動で送る「自動キャスト」アドオン**です。

* **1 回押せば 1 回だけ実行します。** 繰り返したり、常駐して自動で戦ったりはしません。
* 連携が起きない・詠唱が中断されたなど、**失敗したらその場で止まります**（失敗したまま入力を送り続けることはありません）。
* Windower を含む外部ツールの利用は、FFXI の利用規約では認められていません。アカウントの停止などの措置を受ける可能性があり、使用による不利益について、作者は責任を負えません。**自己責任**で使ってください。
* **放置・無人での使用はしないでください。** 必ず画面を見ながら、自分の手で押してください。
* 改変して自動戦闘や魔法の連打に使うことはしないでください。

## 実行する内容

| 段 | 使うもの | 起きる連携 |
| :--- | :--- | :--- |
| 準備 | 連環計（効果中なら飛ばす）・黒のグリモア（効果中なら飛ばす） | |
| 1 | 震天動地の章 → エアロ | （始点: 炸裂） |
| 2 | 震天動地の章 → ストーン | 切断 |
| 3 | 震天動地の章 → エアロ | 炸裂 |
| 4 | 震天動地の章 → 土門の計 | 切断 |
| 5 | 震天動地の章 → 風門の計 | 炸裂 |
| 6 | 震天動地の章 → 闇門の計 | **重力** |
| MB | 気炎万丈の章 → **メルトン** | 重力に闇でマジックバースト |

* メルトンは**連環計の効果中にしか詠唱できない**ので、連環計が切れていれば最初に使います（`//m6 tabula` で OFF にできます）。
* 震天動地の章 6 回と気炎万丈の章 1 回は、連環計の効果中なので戦術魔導書を消費しません。
* 連携の窓は、連携が 1 段増えるごとに 1 秒縮みます（10 − 段数）。計略魔法で連携を〆ると 2 秒延びます。6 連目の重力は 5 段目の連携なので、MB の受付は **10 − 5 + 2 = 7 秒**です。
* 魔法の着弾のあと約 3 秒はアビリティを使えない硬直があるので、重力の着弾から 3 秒待って気炎万丈の章、続けてメルトンを撃ちます。メルトンは重力から**約 5.7 秒**で着弾します。
* 大悟徹底は使いません。大悟徹底も入れると、硬直のぶんメルトンの着弾が約 7.2 秒になり、7 秒の受付に間に合わないためです（v1.0.2）。
* 装備の着替えは、Melton6 では行いません。アビリティと魔法を通常の入力として送るだけなので、**いつもの GearSwap がそのまま着替えます**（下記「GearSwap について」）。

## 進み方と止まる条件

* **アビリティ**: 実行のパケットを確かめてから **1 秒** 待って次へ。実行されなかったときは、もう一度だけ使います。
* **気炎万丈の章**: MB 受付に間に合わせるため、使い直さず、実行を待つ時間も 1.5 秒と短くしています。実行されなかったときは、メルトンを撃たずに止めます。
* **魔法**: 詠唱開始と着弾を確かめます。2 段目以降は**狙った連携が起きたか**も確かめ、着弾から **3 秒** 待って次へ進みます。
* **止まる条件**（その場で止まり、理由をチャットに表示します）
  * 詠唱が中断された／詠唱が始まらない／着弾を確認できない
  * 狙った連携が起きなかった
  * アビリティが 2 回とも実行されなかった（気炎万丈の章は 1 回でも実行されなかったとき）
  * ターゲットが変わった・倒れた、エリアを移動した、戦闘不能になった
  * `//m6 stop`

**開始前の確認**: 学者か、敵をターゲットしているか、距離、計略魔法・メルトン・連環計の再使用、MP を確かめます。足りないものがあれば、**何も実行せず**に全部知らせます（連環計を無駄にしないため）。

**完了時の表示**: MB の成否、重力の着弾からメルトンの着弾までの秒数、MB の受付の秒数、敵の名前を表示します。

```
[Melton6] メルトンでマジックバースト成功！ (6連携 / 気炎 / 重力から 5.73秒 / 受付 7.0秒 / Achuka)
```

## GearSwap について（最大限に使うために）

Melton6 は**装備の着替えを行いません**。アビリティと魔法を通常の入力として送るだけなので、着替えは GearSwap に任せる作りです。

* Melton6 だけでも動きますが、**最大限に使うには GearSwap が必要**です。
* GearSwap が無いと、詠唱前のファストキャスト、震天の魔法の装備、メルトンの MB 装備に着替えません。詠唱が長くなって MB 受付（7 秒）に間に合わなくなったり、メルトンのダメージが大きく下がったりします。

### おすすめ: 「WindowerでFF11ライフ」の GearSwap コード
作者は、**[WindowerでFF11ライフ（greeds.net）の GearSwap コード](https://greeds.net/gearswap-code-list/)** を主軸に使っています。Melton6 もこの環境で動作を確かめています。

* 学者のジョブロジック **`SCH.lua`** と、装備定義 **`SCH_gear.lua`** を導入し、`SCH_gear.lua` を自分の装備に書き換えて使うのがおすすめです。
* 置き場所は、配布ページの説明どおりです（`GearSwap/data/` にジョブロジックと `user-globals.lua`、キャラクター名のフォルダーに装備定義など）。導入方法や最新の構成は、配布ページを確認してください。
* Melton6 は個人で作ったアドオンで、greeds.net とは関係ありません。GearSwap のコードについての質問は、Melton6 ではなく配布元の案内に従ってください。

## 装備のヒント（GearSwap 側）

* **ファストキャスト**: シェオル ジェールのようにサポートジョブが Lv0 になる場所では、サポ赤の特性 FC がありません。**装備だけで FC 上限 80%** を目指すと安定します。
* **武器種をそろえる**: FC・震天・MB の各セットで武器の種類が変わると、着替えのたびに見た目が切り替わります。同じ武器種（片手棍と盾など）にそろえると、余計な切り替えがなくなります。
* **震天の魔法**: 連携を作るだけなので、ダメージは抑えて、敵に TP を与えないモクシャ（Subtle Blow）装備にします。
* 参考: [spoiler.jp の学者 MB 装備の記事](https://www.spoiler.jp/blog/2026/03/11schmb/)

## インストールと使い方

1. GitHub リポジトリを開き、**Code → Download ZIP** でファイル一式をダウンロードします。
2. ZIP を解凍し、フォルダー名を **`Melton6`** にします（GitHub の ZIP は `Melton6-main` で解凍されるので `-main` を消してください）。
3. `Windower4/addons/` に `Melton6` フォルダーごと置きます。
4. ゲーム内で `//lua load Melton6` を打って読み込みます。
5. ゲーム内マクロに次の 1 行を登録します。

```
/console m6 go
```

6. `//m6 check` で準備ができているか確かめ、敵をターゲットしてマクロを押します。

※ 最大限に使うには GearSwap も必要です（上記「GearSwap について」）。

## コマンド一覧（`//m6` または `//melton6`）

| コマンド | 内容 |
| :--- | :--- |
| `//m6 go` | 6連メルトンを開始 |
| `//m6 stop` | 途中で止める |
| `//m6 check` | 開始できるか確認だけする（何も実行しない） |
| `//m6 status` | 設定の表示 |
| `//m6 set post <秒>` | 魔法の着弾から次のアビリティまで（初期 3.0・0〜10）。連携が起きないときに調整 |
| `//m6 set postfinal <秒>` | 最後の重力の着弾から気炎万丈の章まで（初期 3.0・0〜5）。魔法のあとの硬直があるので、短くしすぎると「アビリティは使えなかった」で止まります |
| `//m6 set gap <秒>` | アビリティの後の待ち（初期 1.0・0.5〜5） |
| `//m6 set boosttimeout <秒>` | 気炎万丈の章の実行を待つ秒数（初期 1.5・0.5〜5。ほかのアビリティは 2.5） |
| `//m6 tabula` | 連環計が切れていたら自動で使うか（ON / OFF） |

設定の値には範囲があり、範囲の外を指定すると、範囲の中に収めて知らせます（`data/settings.xml` を手で書き換えた場合も、読み込むときに収めます。v1.0.1）。

詳しくは同梱の `COMMANDS.txt` にまとめています。

## 注意事項

* 連環計の再使用は 1 時間です。`//m6 check` で準備ができているか確かめてから使うと安心です。
* 待ち時間の初期値は、参考にしたマクロ（下記）から決め、実戦で確かめています。環境によって連携が起きにくいときは `//m6 set post` で調整してください。
* 6 連の途中や MB の前に、フェイスやパーティーメンバーが同じ敵に WS を撃つと、連携が上書きされたり、MB の受付が終わったりします。TP を先に使わせておくと安心です。
* ダメージが常に 0 の敵（ジュノのカカシなど）では、連携は起きてもメルトンが MB になりません。動作確認は実際の敵で行ってください。
* 参考: [バンバ用6連2アビメルトンMBを安定化 - モーター、あなた疲れてるのよ](https://mortar.hateblo.jp/entry/2023/06/15/195116)

## 更新履歴

* **v1.0.2 (2026-10-29)**
  * メルトンが MB にならなかったのを直した。MB の受付は連携の段数で縮み、6 連は 7 秒（10 − 5 段 + 計略魔法の 2 秒）。大悟徹底 → 気炎万丈の章 → メルトンでは、着弾が重力から 7.2〜7.5 秒になり、受付を過ぎていた。
  * **大悟徹底を外し、気炎万丈の章 → メルトンにした。** 魔法のあと約 3 秒の硬直があり、待ちを詰められないため。メルトンは重力から約 5.7 秒で着弾する。
  * 重力の着弾から気炎万丈の章までの待ちを、新しい設定 `//m6 set postfinal`（初期 3.0 秒）に分けた。
  * MB の受付を段数から計算し、結果の表示に受付の秒数を出すようにした。
  * ゲーム内で確かめたこと: 6 連 → 気炎万丈の章 → メルトンで MB 成功（重力から 5.73 秒）。
* **v1.0.1 (2026-10-28)**
  * 設定の値に範囲を設けた（使い直しの回数 0〜2、待ち時間など）。範囲の外の値（`//m6 set retries 50` や、0・負の数など）では、入力を何度も送ったり、待ちが効かずに続けて送ったりすることがあった。
  * 開始前の確認に、エアロ・ストーンの再詠唱を足した（直前に使っていると、2 手目で止まって連環計が無駄になるため）。
  * 結果（MB 成功・失敗）の表示に、対象の敵の名前を出すようにした。
  * ゲーム内で確かめたこと: 6 連目の重力まで進み、メルトンが着弾すること・範囲の外の値を収めること。
* **v1.0.0 (2026-10-09)**
  * 初版リリース。震天 6 連携 → 大悟徹底・気炎万丈の章 → メルトン MB をマクロ 1 回で実行。
  * アクションパケットで実行・着弾・連携・MB を確かめて進み、失敗したら止まる。
  * 大悟徹底・気炎万丈の章は、どちらか一方が実行されればメルトンまで続行。
